    Bericht für die Ärztin

    Erstellt ein PDF mit 8-Wochen-Übersicht, häufigsten Schmerzorten, Bewegung und allen Tageseinträgen. Danach öffnet sich meist das Teilen-Menü, dort dein Mail-Programm wählen. Kann dein Browser das nicht (z. B. Firefox), landet die Datei unter „Downloads“ (Samsung: App „Eigene Dateien“) und du kannst sie von dort per Mail verschicken.

    Backup

    Alle Einträge bleiben nur auf diesem Gerät, es wird nichts an einen Server geschickt. Sichere deshalb einmal pro Woche ein Backup: Danach öffnet sich meist das Teilen-Menü, dort dein Mail-Programm wählen und an dich selbst senden. Bei Firefox landet die Datei unter „Downloads“ (Samsung: „Eigene Dateien“), von dort kannst du sie per Mail an dich schicken. Nach 7 Tagen erinnert dich das Tagebuch.

    Einstellungen

    Tipp: Lege das Tagebuch auf den Startbildschirm, dann öffnet es sich wie eine App. iPhone (Safari): Teilen → „Zum Home-Bildschirm“. Android (Firefox, Chrome oder Samsung Internet): Menü ⋮ bzw. ☰ → „Zum Startbildschirm hinzufügen“ bzw. „Installieren“. Nutze immer denselben Browser, sonst siehst du deine Einträge nicht.
